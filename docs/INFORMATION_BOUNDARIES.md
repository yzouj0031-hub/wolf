# 玩家视角信息边界

本次修复覆盖中文与英文客户端的 API 系统提示词、网页接力、个人战报及私密行动重建。

- 玩家编号必须唯一且与座位索引一致；姓名必须唯一。加载坏存档前拒绝，生成个人输入前再次校验，不自动重编号或猜测历史记录归属。
- 私密夜间记录优先按 `casterId` / `playerId` 授权；显式编号冲突时不能用同名或同角色兜底。具名旧记录只允许唯一同名玩家读取。
- 未记录行动者的旧技能记录，仅当全员（包括死者）中该角色唯一时允许回退。重复角色的无归属记录不展示。
- 预言家、女巫、守卫、魔术师、机械狼等仍使用全局技能状态的重复角色配置，会明确阻止对应玩家生成提示词，不能将此保护理解成引擎已支持多个该类角色。
- 狼队共享刀口与密谈使用统一的狼队成员判定；机械狼、石像鬼不因此获得普通狼队信息。
- 子狐媚惑的受术者只收到经过删减的技能反馈，不获得施法者身份或其他目标结果。女巫历史刀口仅保留其持有解药时的合法视角。
- 缺失石像鬼查验结果时显示缺失，不从当前底牌表补写历史答案。
- 自动身份摘要只提取明确的本人声明，保留时间顺序与已死亡发言者；转述、否定、推测等不生成金水/查杀。漏摘时仍可读原始发言。多人报金水不再升级为系统认证或默认队友。

## 离线验证

`npm test` 包含无浏览器依赖的 `scripts/test-information-boundaries.mjs`。

另有可选浏览器集成测试：

- `npm run test:public-claims:browser`
- `npm run test:information-boundaries:browser`

需单独提供 Playwright 和浏览器。可设置 `PLAYWRIGHT_MODULE` 为其模块路径，`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 为 Chromium/Chrome 可执行文件。测试使用隔离的临时浏览器上下文并拦截 HTTP(S)，不使用玩家密钥、不调用模型 API。

浏览器测试检查实际组装的三条输出路径，并验证授权信息既不串给别人，也不会全部被删空。测试通过不代表对所有自定义规则、历史存档和外部模型输出作绝对安全保证。

## 已存在的上下文

修复不会修改历史发言或删除存档，也不能撤回已复制到外部 AI 会话的错误摘要。验证新版本建议新开测试局、为网页端 AI 使用新会话；不要把旧污染上下文继续复用后误认为修复无效。
