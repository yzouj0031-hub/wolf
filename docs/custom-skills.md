# 自创技能·积木系统 设计稿

目标：让用户在 UI 里用**可复用的效果积木**拼出自创角色技能，且**真在引擎里生效**（不是只喂 AI 的人设文本）。
分两期落地；本文档是设计底稿，随实现更新。

---

## 一、积木模型

一个自创技能 = `触发时机` + `目标规则` + `一个或多个效果块`（可按目标阵营分支）。

### 效果块（第一期）
| 块 | 作用 | 复用/新增 |
|---|---|---|
| `inspect` 查验 | 得知目标阵营（狼/好人） | 复用预言家 |
| `protect` 守护 | 目标当晚免疫狼刀 | 复用守卫 |
| `poison` 毒杀 | 目标当晚死亡 | 复用女巫毒 |
| `blockKill` 封刀 | 触发则**当晚全体狼无法击杀** | 新增 |
| `muteSkill` 封技能 | 目标**当晚的夜间主动技失效** | 新增 |
| `delayedDeath` 缓死 | 见白猫；改死亡时机 | 新增 |

### 效果块（第二期）
| 块 | 作用 |
|---|---|
| `grantSkill` 授予技能 | 给某玩家临时获得【查验/毒/盾】之一（奇迹商人） |
| `reflect` 反弹 | 打到指定目标的查验/守护/毒，改为落到施法神职自己身上（封锁者） |

### 修饰
- `startRound`：第 N 晚起才可用（子狐=2）
- `uses`：`nightly`（每晚）/ `once`（一次性，触发后消耗）
- `canTargetSelf`：能否选自己（默认否）
- `feedback`：施法者是否收到私密反馈（如"你媚惑的X是狼"）
- `byTargetTeam`：按目标阵营分支不同效果（子狐核心）

## 二、样板角色

### 子狐 🦊（第一期）
- 阵营：神职（好人）
- 技能「媚惑」：`startRound=2`，`uses=nightly`，每晚选 1 人（不可选自己）
  - 目标是**狼阵营** → `blockKill`（当晚全狼禁刀）
  - 目标是**好人阵营** → `muteSkill`（目标当晚夜间技能失效）
  - `feedback=on`：私密告知子狐"你媚惑的X是狼/好人"
- 「封技能」范围：只封**当晚夜间主动技**（预言家查/女巫药/守卫守）；被动与死亡技（猎人枪/狼王咬）不封；白天技（骑士决斗）不封。

### 白猫 🐈‍⬛（第一期）
- 技能「缓死」（被动）：被**任意方式**判出局的瞬间不死，挂缓死标记、**继续正常存活**（可发言/投票/用技能），并**立即公开身份**（翻牌亮明"白猫·缓死中"）。
- 死亡时机：**下一轮的同一种阶段**才真正死亡。
  - 🌙 夜里被刀 → 下一个夜晚结算死
  - ☀️ 白天被投/枪杀/自爆 → 下一个白天投票阶段死
- 细则：缓死期间**算活人**（可拖延胜负判定）；缓死期间再受致命伤忽略；被白狼王自爆带走也享受缓死。

### 奇迹商人 🎪（第二期）
指定一名幸运儿赐予【查验/毒/盾】三选一；幸运儿若是狼 → 不给技能且当场出局。
**待定**：三技能由商人选/随机/幸运儿自选；赐予为当晚一次性还是持续；商人每晚可赐还是一次性。

### 封锁者 🔗（第二期）
当晚选一名玩家 X，凡查验/守护/毒打到 X 的都反弹到施法神职自己身上；触发一次后失去封锁。
**待定**：是否属狼阵营；反弹是"任意一种挡一次"还是"三种各一次"。

## 三、引擎接入思路（低改动、集中式）

核心：**不逐个改几十处按 role.id 的分发**，而是把自创技能的产出收进 `S.nightData.customFx`，在 `resolveNight` 的**最前面**做一次预处理，按积木改动局面：

1. **夜间收集**：给"带自创技能的角色"加一段通用夜间提问 → 写入 `S.nightData.customFx = [{caster, blocks, target, ...}]`。
2. **resolveNight 预处理**（在结算刀口/毒/查验之前）：
   - `blockKill` → 置 `S.nightData._noKill=true`；刀口结算最前面加一句判断。
   - `muteSkill` → 调 `suppressNightSkill(targetId)`：按目标 role.id 清掉其写入的 nightData 贡献（seer/guard/witch…），一个集中函数搞定。
   - `inspect/protect/poison` → 复用既有字段。
3. **缓死**：`killPlayer` 检测到目标带 `delayedDeath` 且首次出局 → 不真正结算，改为登记 `pendingDeath={phase, dieAtRound}` + 立即翻牌公开；在每个夜间结算 / 白天投票阶段开头检查到期者，届时才真死。
4. **胜负**：缓死者在真死前一律计入存活。

单测覆盖积木纯逻辑；真实 AI 对局平衡由作者用 key 实测后微调。
